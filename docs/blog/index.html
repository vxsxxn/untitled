Notes on Untitled — what it does, how it works, why it's built this way.

What Untitled is

A tool that runs on your computer and does tasks for you.

  other AI agents          Untitled
──────────────────        ──────────────
runs on a server          runs on your computer
your chats train it       your files stay yours
lock-in, export later     open formats, leave anytime
Nothing goes out without you

How Untitled asks before it acts — and what it never asks for.

  agent wants to:
    read a file         → fine, it's local, yours anyway
    rename your notes   → fine, it's local, yours anyway
    send an email       → you approve first
    spend money         → you approve first
Your data stays yours

Open formats, plain folders, no export ceremony.

  $ ls ~/untitled
    profiles/   memories/   vault/   sessions/

  copy the folder → done. that's the whole export.
Why a desktop app

Because installing Python and editing YAML is not an on-ramp.

  before:  terminal → python → config → debug

  now:     download → double-click → it opens
Installing Untitled

Two minutes on Mac, Windows, or Linux.

  Mac:     double-click the .command file
  Windows: double-click the .cmd file
  Linux:   bash Untitled-install-linux.sh
