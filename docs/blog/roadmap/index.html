About the app

What's next for Untitled

Two features we're building because they're the two moments everyone gets stuck.

  stuck point #1   the site wants a login the agent can't do
    → vault logins:   the app holds your logins, encrypted;
                      the agent uses them, never sees them

  stuck point #2   the site demands a human (CAPTCHA, 2FA)
    → screen handoff: the app shows you the exact moment,
                      you take over in one click, hand back

Vault logins come first. Most real tasks die at a login screen, and pasting passwords into a chat is the one habit we refuse to encourage. The vault already exists in the engine; we're wiring it into the desktop flow so it feels like "the app knows this site" instead of "I managed credentials again".

Then the screen handoff. Today, when a site demands a human, the agent stops and says so. Next, the app will mirror the browser view at that exact moment: you type the CAPTCHA or the code, and the task continues. No screenshots sent anywhere — the mirror is local, same as everything else.

After that: fewer clicks in approvals, a mod system for adding abilities, and whatever you tell us is still in the way. Tell us.
