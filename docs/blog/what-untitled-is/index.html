About the app

What Untitled is

One sentence: software that runs on your own computer and does tasks for you.

  other AI agents          Untitled
  ───────────────          ───────────
  runs on a server         runs on your computer
  your chats train it      your files stay yours
  lock-in, export later    open formats, leave anytime

Untitled is not a personality and not a friend. It's a tool, like a compiler or a spreadsheet. You give it a task, it does it, you check the work. That's the whole relationship, and that's the point.

It can read and write files on your machine, browse the web, run commands — the things you'd do yourself if you had the time. Every action that matters goes past you first (more on that in the approvals post).

It's built for people who don't want to become engineers to use an AI agent. Download, double-click, paste an API key into Settings, start talking to it. If you want to look under the hood, it's MIT licensed and the code is on GitHub.
