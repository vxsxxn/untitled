Installing Untitled

Download, double-click, done.

  Mac:     download Untitled-install-mac.zip
           double-click the .command file

  Windows: download Untitled-install-windows.cmd
           double-click it

  Linux:   download Untitled-install-linux.sh
           bash Untitled-install-linux.sh

The installer clones the repo into ~/untitled, sets up Python in a private folder (it won't touch your system Python), and launches the desktop app. Your browser opens to the app's own address — there's no cloud dashboard, it lives on your machine.

First run, it walks you through setup in plain language: paste your API key into Settings and you're talking to it. Everything it asks for is visible later in Settings, and nothing is collected.

Updating is the same gesture — run the installer again and it updates the existing copy instead of reinstalling. Uninstalling is deleting the folder.
